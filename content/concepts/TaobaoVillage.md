# 淘宝村 (Taobao Village)

淘宝村是中国农村经济与电子商务深度融合的独特经济现象。根据[[AliResearch]]的定义，"淘宝村"是大量网商聚集在某个村落，以淘宝为主要交易平台，以淘宝电商生态系统为依托，形成规模和协同效应的网络商业群聚现象。

## 认定标准（三条原则）

1. **交易场所**：经营场所在农村地区，以行政村为单元
2. **交易规模**：电子商务年交易额达到 1000 万元以上
3. **网商规模**：本村活跃网店数量达到 100 家以上，或活跃网店数量达到当地家庭户数的 10%以上

## 形成原因

1. **电子商务加速向农村渗透**：农村网民快速增长，互联网基础设施改善
2. **第三方平台降低创业门槛**：淘宝网提供低成本、低风险的创业途径
3. **农村"熟人社会"属性**：涟漪效应，网商向亲友、邻居快速扩散
4. **基础设施持续改进**：物流、宽带、交通条件不断改善
5. **电子商务带头人的关键作用**：善于学习、勇于尝试、乐于分享的先行者

## 主要特点

- **农民网商主导**：农户自己变身为网商直接对接市场
- **集群性**：网商大多经营同一品类产品，形成网络产业集群
- **协同性**：得益于熟人社会，网商在竞争的同时也进行产品流通和经验分享

## 从 1.0 到 2.0 的升级路径

根据[[taobao-village-decade-review-2009-2019]]，淘宝村发展经历三个阶段：

- **萌芽期（2009-2013）**：草根创业、自发成长、自家院子——从 3 个到 20 个
- **扩散期（2014-2018）**：集群发展、政府支持、产业园区——从 212 个到 3202 个
- **爆发期（2019-）**：企业化、生态化、新型工业化、社区建设、治理创新——突破 4000 个

淘宝村 1.0 阶段以草根自发、小作坊、无品牌为特征。2.0 阶段呈现四大趋势：

- **集约化**：个体网商向企业网商转变，协会联盟发挥组织作用
- **品牌化**：注册品牌商标，建立网络知名度
- **生态化**：物流、代运营、培训等服务商完善产业链
- **扩散化**：从村向镇、县域蔓延
