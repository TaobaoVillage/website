# 新都村

新都村位于浙江省[[临安市]]清凉峰镇，与[[白牛村]]相邻，同属山核桃电商集群。

## 核心数据

- 主营产品：坚果炒货（山核桃）
- 2014 年清凉峰镇因拥有 3 个淘宝村被认定为[[淘宝镇]]
